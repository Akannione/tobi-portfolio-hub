Transcript-Grounded Learning Agent

Automation flow

From channel scan to durable local guidance.

  1. 01Scan configured RSS feeds and channel archives.
  2. 02Score and select relevant AI engineering candidates.
  3. 03Reuse cache or retrieve transcript text with bounded fallbacks.
  4. 04Generate Markdown outputs and promote only novel durable lessons.
  5. 05Refresh status, send a phone-friendly summary, and log channel outcomes.

Reliability rules

The agent is designed to say when it does not know.

  • No transcript means no analysis.
  • Known failures stay cached instead of triggering blind retries.
  • Repeated lessons do not create duplicate workflow rules.
  • Every run records changed, learned, blocked, and next.

Business value

Turn repeated research into a controlled learning system.

Cache-first execution reduces repeated transcript calls and avoids wasting time on known failures.

Novelty checks keep the local workflow library concise instead of accumulating duplicate advice.

Structured summaries make each run reviewable and create a reusable pattern for research monitoring services.

Technical stack

Python CLI, YouTube RSS, transcript APIs, yt-dlp fallback, JSON cache, Markdown outputs, unittest, macOS Messages and Reminders.
